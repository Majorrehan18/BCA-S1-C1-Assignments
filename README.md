# 🎓 BCA-S1-G1-Assignments

Welcome to the official GitHub repository for **BCA Semester 1 — Section G1**.

This repository is used to **collect students' assignments directly on GitHub**.

The purpose is to keep everyone's assignment work organized and make submission and review easier.

---

# 🧑‍🎓 How To Submit Your Assignments

Follow these steps carefully.

## 1️⃣ Fork This Repository

First, create your own copy of this repository.

On the GitHub repository page:

**Fork → Create Fork**

You will now have your own copy of this repository under your own GitHub account.

---

# 🚨 2️⃣ VERY IMPORTANT — USE THE `Assignment` BRANCH

After forking the repository, **DO NOT work on the** **`main`** **branch.**

You must switch to the branch named:

`Assignment`

### ⚠️ Remember

> **All student's assignment work must be done in the** **`Assignment`** **branch.**

The branch `Assignment` is the branch used for student submissions.

---

# 📂 3️⃣ Create Your Own Folder

Inside the `Assignment` branch, create a folder with **your name**.

⚠️ Important

**Do not put your files directly inside the** **`Assignment`** **branch.**

Your work must be inside **your own folder**.

Ask the Managers for this Step.

---

# 📄 4️⃣ Upload or Create Your Assignment Files

Once you have created your folder, put your completed assignment files inside it.

You can either:

* Upload files from your computer
* Create a new file directly on GitHub
* Upload multiple files if required

Example:

```text
Assignment/
└── Rehan-Moyal/
    ├── Assignment-1.c
    ├── Assignment-2.c
    └── Assignment-3.c
```

Only upload the files required for the Assignment.

---

# 💾 5️⃣ Commit Your Changes

After uploading or creating your files, GitHub will ask you to **commit your changes**.

Enter a simple commit message.

Example:

```text
Submitting assignment
```

Then select:

**Commit changes**

Your files are now saved in your fork.

---

# 🔀 6️⃣ Create a Pull Request

After completing your assignment, create a **Pull Request (PR)** from your fork to the original repository.

# 🚨🚨 MOST IMPORTANT RULE 🚨🚨

## ❌ DO NOT SEND YOUR PULL REQUEST TO `main`

Your Pull Request **must target the** **`Assignment`** **branch** of the original repository.

### ✅ Correct

```text
Your Fork / main
        ↓
Original Repository / Assignment
```

### ❌ Wrong

```text
Your Fork / main
        ↓
Original Repository / main
```

If you send your assignment to `main`, it is **A WRONG SUBMISSION**.

**Always check the target branch before creating your Pull Request.**

---

# 👨‍🏫 7️⃣ What Happens After You Submit?

After you create your Pull Request:

1. Your submission will be reviewed.
2. Your files may be checked for mistakes.
3. If something needs to be changed, you may be asked to make corrections.
4. Make the corrections in your fork.
5. Your existing Pull Request will automatically update.
6. Once everything is correct, the Pull Request can be approved and merged.

### 🔄 If changes are requested

**Do not create a new Pull Request unnecessarily.**

**Simply make the requested changes in your fork and commit them.**

Your existing Pull Request will update automatically.

---

# ⚠️ Rules Students Must Follow

### 🔴 Important Rules

1. Always work in your **Own Fork**.
2. Always use the **`Assignment`** **branch** for assignment work.
3. Create a **separate folder for yourself**.
4. Keep your assignment files inside your own folder.
5. Do not modify another student's folder.
6. Do not delete another student's work.
7. Do not submit your assignment directly to `main`.
8. Your Pull Request must target the original repository's **`Assignment`** **branch**.
9. Submit only your own work.
10. Check your files before creating the Pull Request.
11. If changes are requested, update the existing Pull Request.
12. Keep your files properly organized.

---

# 📝 Folder Naming Convention

Your folder should contain **your name**.

### ✅ Examples

```text
Assignment-Rehan-Moyal
Assignment-Arsalan
```

### ❌ Avoid

```text
New Folder
My Assignment
Assignment
test
```

### 🚨 Important

Before creating your folder, check whether your folder already exists.

**Do not create a second folder for yourself.**

For example, avoid:

```text
Rehan-Moyal/
Rehan-Moyal-1/
```

Use your existing folder instead.

# ❓ Common Mistakes

| ❌ Mistake                                       | ✅ Correct Action                     |
| ----------------------------------------------- | ------------------------------------ |
| Working on `main`                               | Switch to `Assignment`               |
| Creating `Assignment-01` branch                 | Use the existing `Assignment` branch |
| Putting files directly in `Assignment`          | Create your own folder first         |
| Editing another student's folder                | Only use your own folder             |
| Sending PR to `main`                            | Send PR to `Assignment`              |
| Creating a duplicate folder                     | Check for your folder first          |
| Forgetting to commit                            | Commit your changes after uploading  |
| Creating another PR after changes are requested | Update the existing PR               |
| Uploading unnecessary files                     | Upload only assignment-related files |
